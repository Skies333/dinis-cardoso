# Dinis Cardoso — Portfólio

Site de portfólio do designer Dinis Cardoso (Lisboa): design de marca, UX/UI e design de interiores.

**Ver online:** https://skies333.github.io/dinis-cardoso/

## Idiomas
- Português (PT-PT) — idioma principal, na raiz do site.
- Inglês — em [`/en/`](en/index.html). O seletor PT/EN troca entre as duas versões da mesma página.

## Estrutura
```
index.html                    Página inicial (PT)
projects/                     Todos os projetos + página de cada projeto (PT)
en/                           Versão em inglês (mesma estrutura)
assets/css/style.css          Estilos
assets/js/main.js             Interações (menu, filtros, linha do tempo, galeria)
assets/js/motion.js           Animações
assets/img/                   Imagens (.webp)
assets/fonts/                 Manrope e Inter
```

Site estático — não precisa de build. Publicado com GitHub Pages a partir da branch `main`.
