DINIS CARDOSO — PORTFÓLIO (versão nova)
=======================================

Site estático: basta enviar esta pasta inteira para qualquer alojamento
(Netlify, Cloudflare Pages, GitHub Pages, FTP…). Não precisa de instalar nada.

IDIOMAS
  Português (PT-PT) é o idioma principal e fica na raiz do site.
  Inglês fica em en/ (ex.: en/index.html). O botão PT/EN no menu troca entre as duas versões da mesma página.

ESTRUTURA
  index.html                     Página inicial (hero, projetos, serviços, sobre mim, contacto)
  projects/<projeto>/index.html  Páginas de cada projeto (next, porta4a, pna, vitae, next-interfaces)
  assets/css/style.css           Todo o visual (cores e fontes no topo, em :root)
  assets/js/main.js              Animações e formulário
  assets/img/                    Imagens (otimizadas em .webp)
  assets/fonts/                  Manrope e Inter

FORMULÁRIO
  Como o site é estático, "Send message" abre a app de email de quem visita,
  com o nome, o email e a mensagem já preenchidos. Para receber mensagens
  diretamente, podes ligar o formulário a um serviço como o Formspree ou o Netlify Forms.

VER NO COMPUTADOR
  Abre o index.html no navegador.
